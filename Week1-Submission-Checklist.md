# Week 1 Submission Checklist — Vortex Tech Academy

Use this checklist before submitting the repository link through the Week 1 form sent by Vortex Tech Academy.

- [ ] Create or open the public GitHub repository you will use for the internship submission.
- [ ] Add `README.md` to the repository root. If a README already exists, update it carefully instead of deleting useful existing content.
- [ ] Add `Week1-OWASP-Top-5-Research.md` to the repository root.
- [ ] Open the report in GitHub Preview and check headings, source links, and the four-sentence reflection.
- [ ] Confirm repository visibility is **Public** and both files open without signing in.
- [ ] Copy the repository URL from the browser address bar.
- [ ] Open the Week 1 submission form link supplied in the Vortex Tech Academy email.
- [ ] Enter your name and track exactly as requested in the form. Suggested track wording from the task brief: `Cyber Security Internship Track`.
- [ ] Paste the public GitHub repository URL into the form.
- [ ] Submit the form and keep any confirmation message/email.

**Important:** The report is prepared, but Week 1 is not fully submitted until the files are pushed to a public repository and the official form is submitted.
