# Vortex Tech Cybersecurity Internship

Hands-on cybersecurity learning and authorized security lab practice completed during my **Cybersecurity Internship at Vortex Tech Academy**.

Vortex Tech Academy — Week 1 OWASP Research
This public portfolio repository contains my Week 1 Cyber Security Internship research for Vortex Tech Academy.
Main submission
- [`Week1-OWASP-Top-5-Research.md`](Week1-OWASP-Top-5-Research.md) — a beginner-friendly research report on five categories from the official OWASP Top 10:2025 list. Each category includes a definition, a high-level attack scenario, a real-world case, practical mitigations, and source links. It concludes with a four-sentence personal reflection.
Topics covered
1. A01:2025 — Broken Access Control
2. A02:2025 — Security Misconfiguration
3. A03:2025 — Software Supply Chain Failures
4. A04:2025 — Cryptographic Failures
5. A07:2025 — Authentication Failures
How to view this project
This is a Markdown research/documentation submission; no code installation or execution is required. Open the report above in GitHub to read it. References to OWASP, government advisories, and documented case studies are included in the report.
Learning focus
The goal is to understand common web application risks, how weaknesses can be abused at a high level, the consequences seen in real incidents, and practical ways to reduce risk.
